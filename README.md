# 📊 SQL Data Job Market Analysis

## 📌 Introduction

This project explores the **Data Analyst job market** using SQL.  
It focuses on identifying:

- 💰 Top-paying jobs  
- 🔥 Most in-demand skills  
- ⚖️ Skills with high demand and high salary  

The objective is to help aspiring data professionals make **data-driven career decisions**.

---

## 🎯 Background

With the growing demand for data analysts, understanding **which skills and roles offer the best opportunities** is essential.

This project analyzes a dataset of job postings containing:

- Job titles  
- Salary information  
- Job locations  
- Required skills  

---

## ❓ Key Questions Answered

1. What are the top-paying data analyst jobs?  
2. What skills are required for these jobs?  
3. What are the most in-demand skills?  
4. Which skills offer the highest salaries?  
5. What are the most optimal skills to learn?

## 📊 Analysis & Insights

### 1️⃣ Top Paying Data Analyst Jobs

- Filtered highest salary jobs  
- Focused on remote roles  

💡 **Insights:**
- Salaries can exceed **$300K+**  
- Senior roles offer significantly higher pay  
- Tech companies dominate high-paying jobs  

---

### 2️⃣ Skills Required for Top-Paying Jobs

- Extracted skills from high-paying roles  

💡 **Insights:**
- SQL is required in most jobs  
- Python and Tableau are highly valuable  
- Cloud technologies are increasingly important  

---

### 3️⃣ Most In-Demand Skills

💡 **Top Skills:**
- SQL  
- Excel  
- Python  
- Tableau  
- Power BI  

💡 **Insights:**
- SQL is the **most demanded skill**  
- Excel remains important for entry-level roles  
- Visualization tools are essential  

---

### 4️⃣ Highest Paying Skills

💡 **Insights:**
- Big data tools (PySpark, Databricks) offer highest salaries  
- Cloud tools (AWS, Azure) increase earning potential  
- Advanced tools lead to better compensation  

---

### 5️⃣ Optimal Skills (High Demand + High Salary)

💡 **Best Skills to Learn:**
- SQL  
- Python  
- Cloud platforms  
- Data visualization tools  

💡 **Strategy:**
- Start with SQL + Excel  
- Advance to Python + Cloud
