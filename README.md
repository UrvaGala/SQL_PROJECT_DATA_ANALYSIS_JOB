# 📊 SQL Data Job Market Analysis

## 📌 Introduction

This project analyzes the **Data Analyst job market** using SQL to uncover:

- 💰 Top-paying jobs  
- 🔥 Most in-demand skills  
- ⚖️ Skills with high demand and high salary  

The goal is to help aspiring data professionals make **data-driven career decisions**.

---

## 🎯 Background

With the rapid growth of data-related roles, understanding **which skills actually matter** is essential.

This project uses a dataset of job postings containing:

- Job titles  
- Salary information  
- Job locations  
- Required skills  

---

## ❓ Key Questions Answered

1. What are the top-paying data analyst jobs?  
2. What skills are required for these jobs?  
3. What are the most in-demand skills?  
4. Which skills offer the highest salaries?  
5. What are the best skills to learn?

## 📊 Analysis & Insights

### 1️⃣ Top Paying Data Analyst Jobs

- Identified highest-paying roles  
- Focused on remote jobs  

💡 **Insights:**
- Salaries can exceed **$300K+**  
- Senior roles earn significantly more  
- Tech companies dominate high-paying jobs  

---

### 2️⃣ Skills Required for Top-Paying Jobs

💡 **Insights:**
- SQL is required in most jobs  
- Python and Tableau are highly valuable  
- Cloud tools are increasingly important  

---

### 3️⃣ Most In-Demand Skills

💡 **Top Skills:**
- SQL  
- Excel  
- Python  
- Tableau  
- Power BI  

💡 **Insights:**
- SQL is the **most demanded skill**  
- Excel is still widely used  
- Visualization tools are essential  

---

### 4️⃣ Highest Paying Skills

💡 **Insights:**
- Big data tools (PySpark, Databricks) offer highest salaries  
- Cloud tools (AWS, Azure) increase salary potential  
- Advanced tools lead to better pay  

---

### 5️⃣ Optimal Skills (High Demand + High Salary)

💡 **Best Skills to Learn:**
- SQL  
- Python  
- Cloud platforms  
- Data visualization tools  

💡 **Strategy:**
- Start with SQL + Excel  
- Advance to Python + Cloud
